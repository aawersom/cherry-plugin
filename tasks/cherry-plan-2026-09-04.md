## Как проверять (стенд = эмулятор cherryRoot, Lampa top.rootu.lampa, CDP 127.0.0.1:9229)
- Поднять/починить стенд: `bash test/tv-reset.sh` (тёплый) или `bash test/tv-cold-restart.sh` (холодный, с DNS 8.8.8.8 — после холодного старта DNS гостя умирает). Оба сами снимают нативный диалог «Update available» (BACK) и пробрасывают CDP. Все adb-вызовы только с `timeout`.
- Полная матрица по каналам: `node test/tv-audit6.mjs [ids]` (каталог, категория, стр. 2, поиск, превью, похожие, модели, воспроизведение с IP устройства, задержки).
- Постеры (реальная загрузка `<img>`): `test/tv-thumb-load-all.mjs`; превью-клипы: `test/tv-diag-preview.mjs`.
- Поиск/релевантность: `test/tv-verify-relevance.mjs`; реальный грид общего поиска: `test/tv-verify-globalrank.mjs <query>`.
- Интерфейс (скриншоты, реальные компоненты): `test/tv-ui-shots.mjs`, `test/tv-verify-ui2.mjs`; избранное: `test/tv-fav-posters.mjs`, `tv-fav-legacy.mjs`, `tv-fav-order.mjs`, `tv-fav-real.mjs`; добавить запись по ссылке: `test/tv-fav-add.mjs <url> <pin>`.
- Произвольный пробник на странице: `node test/tv-page-run.mjs <page.js>` (код страницы — в отдельном файле, без template-literal/бэктиков в bash).
- Деплой: cp plugin.js → plugin-release/, commit + push master и main, `gh release create vX`, проверить md5 LIVE (норм. CRLF/BOM). Бэкап — `backups/<дата>-<тема>/` (bundle + plugin.js).
- Синхронизация избранного: бакет на CF-воркере по PIN (PIN — в локальном vault, не в репо); читать: `POST /favs?pin=…&key=…` с `{"records":[]}`.

## Известные грабли
- Инъекция плагина в стенд: для UI нужен `startPlugin` (window.appready=true, патч `cherry_filter_btn_ready` → `if (true) return;` чтобы не дублировать кнопку); для чистых проверок адаптеров — патч `if (window.appready)` → `if (false)`.
- Тяжёлые eval (сотни Image()) валят WebView → сброс стенда.
- Пробники должны ходить транспортом адаптера (`cherryFetch`/`_fetchAny`): lenporno — force-proxy (натив = зеркало), pornve блокирует прокси (16-байтные ответы).
- В тестах anti-drift проверять код, а не комментарии (комментарии упоминают старые URL).
