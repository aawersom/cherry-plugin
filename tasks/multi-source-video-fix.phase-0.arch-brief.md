## Applicable Invariants

### INV-1 — SOURCES registry integrity
**Rule:** `SOURCES[]` is the single source of truth for all adapters. Every adapter pushes exactly one entry; no dangling references.
**Phase-0 compliance:** After deleting the gayporntube adapter (lines 3633–3708), `SOURCES.length === 25` and zero references to `gayporntube` or its helpers (`_gayptCards`, `_gayptPages`) remain anywhere in `plugin.js` or `test/`. Adapter had no named variable, so no alias cleanup needed.

### INV-2 — Single-file architecture (no module split)
**Rule:** `plugin.js` is one IIFE-guarded file (~3700 lines). New functions must be placed at the correct lexical scope — module-scope helpers vs. local-to-function closures.
**Phase-0 compliance:** `findMatchingBracket` must be declared LOCAL inside `extractStreams`, not at module scope. Placing it at module scope violates this invariant and pollutes the plugin namespace.

### INV-3 — Proxy layer is the only external HTTP path
**Rule:** All outbound requests go through `buildProxyUrl` → `cherryFetch`/`cherryPost`/`proxyM3u8`. `px()` in `playVideo()` wraps every URL handed to `Lampa.Player`.
**Phase-0 compliance:** The new px() guard (REQ-7-PRE) extends, not replaces, the existing `PROXY_URL` guard. Order must be: blob → PROXY_URL → PROXY_URL_2 → protocol-relative fix → buildProxyUrl.

### INV-4 — extractStreams is additive; existing branches are immutable
**Rule:** `extractStreams` is a shared helper consumed by multiple adapters across both tiers. Modifying an existing branch risks silent regressions.
**Phase-0 compliance:** The JWPlayer `sources: [...]` array branch (REQ-2) is inserted BEFORE the existing `jwRe` single-file scan. Zero existing branches are touched. All pre-existing `extractStreams` test cases must remain green.

### INV-5 — Test mirror discipline (plugin-helpers.test.js)
**Rule:** `test/plugin-helpers.test.js` contains an inlined copy of `extractStreams`. Any change to the production function must be mirrored exactly in the test copy, including local sub-functions.
**Phase-0 compliance:** `findMatchingBracket` and the new sources-array branch must appear verbatim in the test copy. Divergence between production and test copy is a latent bug.

### INV-6 — Backslash-parity correctness (escape detection)
**Rule:** Escape detection must count consecutive backslashes: `bs % 2 === 0` = real quote boundary; `bs % 2 !== 0` = escaped. Single-char lookback `html[i-1] !== '\\'` is explicitly wrong.
**Phase-0 compliance:** The bracket-depth scanner and per-object walker in the sources-array branch must implement the `bs % 2 === 0` rule throughout.

### INV-7 — playVideo() is frozen except the one px() line
**Rule:** `playVideo()` is a critical convergence point; unintended changes break all adapters simultaneously.
**Phase-0 compliance:** The only permitted edit to `playVideo()` is inserting the single PROXY_URL_2 guard line inside `px()`. No other logic in `playVideo()` may be touched in Phase 0 or any later phase.

### INV-8 — E2E test count guards are kept consistent
**Rule:** Count guards in `cherry-lampa-e2e.mjs` (lines 528, 639, 691) must equal `SOURCES.length`.
**Phase-0 compliance:** All three must change from 26 → 25, and `gayporntube` must be removed from the tier-B array (line 36).
