# Cherry — UI/UX E2E (Phase 3): рабочий Playwright-харнес

**Дата:** 2026-06-10 · `test/ui-e2e.mjs` · запуск: `npm run test:ui` (или `node test/ui-e2e.mjs`)
**Бесплатно + локально** (Playwright/Chromium, без квот/аккаунтов).

## Как устроено
1. Грузит **настоящую Lampa** (`https://lampa.stream/`) в headless Chromium.
   - lampa.mx даёт SSL-cipher-mismatch в этой среде → используем `lampa.stream` (рабочее зеркало).
2. Проходит онбординг (экран «Выберите язык» → Enter на «Русский» → рендерится главное меню).
3. Инжектит **локальный `plugin.js`** (`window.appready=true` + `addScriptTag`) → Cherry появляется в меню.
4. Открывает реальный Cherry UI (`Lampa.Activity.push({component:'cherry_main'})`) и водит **пультом**
   (стрелки/Enter/Back через `page.keyboard`), снимает скриншоты в `tasks/ui-screenshots/`.

## Ценность
Ловит **UI/UX-регрессии**, невидимые для vitest и stream-matrix: рендер, фокус, навигацию пультом,
переходы между активностями. Это автоматизация «потыкать пультом и посмотреть, что не сломалось».

## Ограничение
Тестирует **браузерный UI** (тот же код компонентов Cherry), НЕ нативный Android-плеер/пульт ТВ.
Воспроизведение видео на нативном плеере + чузер — остаётся в device-чек-листе (Фаза 4).
