# Cherry — кратное улучшение поиска / функционала / дизайна (одобрено 2026-06-14)

Версии: фичи = minor bump (0.9.x → 0.10.0 → 0.11.0…). Каждая фаза верифицируется на эмулятор-стенде
(`test/tv-*.mjs`) + vitest, затем полный деплой. Версия видна в Настройки → «Cherry · vX».

## ФАЗА 1 — Ядро поиска (самый большой рычаг) → v0.10.0
Всё в зоне all_sources-merge + per-source search (контейнерно).
1. **Прогрессивная выдача** — не ждать `Promise.all` всех источников; рендерить карточки по мере
   ответа (быстрые каналы — мгновенно, медленные — дозагружаются). Реализация: резолвить первую
   волну (готовые ≤Nмс), остальное добавлять через пагинацию/догрузку.
2. **Кросс-канальный дедуп** — одинаковое видео на разных сайтах → один раз (ключ = нормализованное
   название + округлённая длительность).
3. **Релевантность с сигналами** — ранг по числу совпавших слов (есть) + точная фраза выше +
   тай-брейк по просмотрам/свежести где есть.
4. **Опечатки/синонимы (лёгкие)** — карта синонимов (milf↔mature, teen↔young…) + нормализация
   (ё→е, регистр, лишние пробелы). Без тяжёлого fuzzy.
5. **Per-channel search надёжность** — каждый канал ищет; авто-проверка на стенде (см. Фаза 5).

## ФАЗА 2 — Ввод поиска → v0.10.x
6. **Голосовой поиск** — нативный микрофон Android TV. Проверить, даёт ли Lampa.Input/системная
   клавиатура голос «из коробки»; если нет — добавить кнопку голос-ввода.
7. **Подсказки: только популярные** (БЕЗ истории — по решению владельца) — статичный список
   популярных терминов как быстрые чипы при открытии поиска.

## ФАЗА 3 — Перцептивная скорость → v0.10.x
8. **Скелетоны/прогрессивная загрузка** — плейсхолдер-карточки во время загрузки гридов
   (главная, категории, поиск, похожие) вместо пустого экрана/спиннера.

## ФАЗА 4 — Функционал → v0.11.0
9. **Единая лента на главной** — секции: «РП» (продолжить), «Свежее со всех каналов», «Популярное»,
   микс источников (не только плитки-каналы).
10. **Кросс-канальные «Похожие»** + навигация по тегам across-каналов.
11. **Единые модели/студии** — там, где сайт поддерживает.

## ФАЗА 5 — Дизайн + Надёжность (фундамент на будущее) → v0.11.x
12. **Единая карточка** — пилюля длительности + бейдж канала + превью + HD, консистентно; внятные
    пустые/ошибка состояния; визуальная иерархия главной.
13. **Гарантированные сортировки** (фильтр остаётся спрятанным): поверх серверных сортов — **клиентский
    сорт** загруженных карточек (по длительности / названию / просмотрам), который РАБОТАЕТ ВСЕГДА,
    даже когда серверный сорт сломан (как pornhub-period). Это «гарантированно лучше».
14. **Фундамент надёжности (закладка)**: контракт возможностей адаптера (`caps:{search,preview,
    duration,related,models}`) + хуки авто-мониторинга дрейфа (расписание `tv-test`/`tv-audit2` на
    стенде) — ловить поломку парсера до жалобы. Полноценный мониторинг — позже; сейчас — архитектура.
