## Фиксы этой сессии (все верифицированы на эмуляторе)

1. **xvideos** — глобальный фид → `/new/{p}` (1-based). Главная `/` и `/best/` НЕ пагинируются
   (стр.2 == стр.1). Бонус: `/new/` отдаёт `data-pvv` → превью стало 100% (было 0%).
2. **pornone** — глобальный фид → `/newest/{p}/`. Старый `/page/{p}/` отдавал 404 (фид капался 1 стр.).
3. **tizam** — глобальный фид → `/fil_my_dlya_vzroslyh/all_sex/?p={n}`. Голый `/?p=` повторял
   один и тот же рейл главной на каждой странице (нет новых карточек).
4. **hellporno** — `browseUrl` → `/hd/{p}/`. Глобальный `/new/{p}/` анти-бот отдаёт стр.1 всегда
   (проверено `/new/100/`==`/new/1/`); категории пагинируются. `/hd/` ≈ весь сайт (почти всё HD).
5. **KVS-движок `browseByModel`** — fallback-URL теперь со СЛЭШем (`…/{page}/`). Без слэша
   `/models/{slug}/{n}` отдаёт 404 → **xozilla/analdin отдавали 0 видео в модели**, теперь 100/30.
   Архитектурный фикс: затрагивает все KVS-модели без своего `videosUrl`.
6. **parseDur** — формат `«17m:37s»` (xozilla) ломал colon-ветку (`Number("17m")=NaN`).
   Теперь смешанный unit+colon падает в unit-скан → xozilla duration 0% → 100%.

## Известные лимиты сайтов (не баги — документировано)

- **Превью отсутствует в гриде** (лениво грузится JS или нет поля): pornone (есть только рекламный
  ливкам-клип `gallery.vcmdiawe.com`), tizam (нет поля), porndig (JS-lazy; инлайн только в сайдбаре),
  ebun (нет поля). eporner/hqporner/porntrex/perfektdamen/lenporno/24rolika — превью-клип не в серверном HTML.
- **Модели — скролл/наполнение ограничены сайтом:**
  - *porndig* — стр. пёрнстара = 40 видео, GET-пагинации нет (DLE-AJAX `load_async_container`).
  - *familyporn* — стр. модели рендерит видео через JS (в HTML 1 ссылка). Nubiles-сеть.
  - *crocotube* — `listScopeRx=/ct-videos-list/` режет стр. пёрнстара (видео в табах вне контейнера)
    + `/pornstars/{slug}/2/` → 404 (нет пагинации).
  - *ebun* — после миграции на `ebun.top` раздел `/models/` = группировки по странам
    («au-model», «actors»…), а не пёрнстары → реального индекса моделей нет (graceful: 0).
- **familyporn `cousin`** — категория по умолчанию нишевая (7 видео, без стр.2). familyporn —
  самый слабый источник (фид сам по себе разреженный).
