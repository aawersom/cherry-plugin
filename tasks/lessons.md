
## 2026-09-05 — регрессия после партии каналов (владелец: pornhub «не открывается», навигация в избранном)
- Матрица `tv-audit6` проверяет адаптеры (карточки/поиск/стрим), но НЕ поведение реального грида: фокус, контроллер, повторная сборка. Регрессию избранного (v0.13.17: `Sync.run()` при открытии → старый `_refreshGrid()` → `comp.create()` поверх построенного грида) она пропустила, хотя избранное «проверялось» — по данным, не по клавишам.
- Правило: после любого изменения, затрагивающего жизненный цикл грида (load/resolve/sync/empty-state), прогонять реальный грид с adb-клавишами: `tv-eval.mjs test/tv-grid-open.page.js "<id|favorites>:9000"` (без инъекции — как в проде) → `tv-state.page.js` после DPAD (фокус должен сдвигаться по индексам). Для избранного — с реальным бакетом через PIN на стенде.
- Второй урок: «не открывается» на ТВ владельца ≠ «не открывается» на стенде (EE-IP). Прежде чем лечить, снимать факты с устройства: тайминги по маршрутам (`tv-ph-timing.page.js`: pornhub натив 4.0 с vs прокси 0.7 с) и спрашивать точный симптом (спиннер / пусто / ошибка).
