# Cherry — UI/UX второй заход: новые идеи (2026-06-06, 8 агентов)

Комплементарно к uiux-deep + UX-batch-1 (там focus/dwell/бейджи/active-state/retry уже сделаны).
Это НОВЫЕ улучшения. Привязано к коду `plugin.js`.

## 🏆 Keystone: ИСТОРИЯ / RESUME / CONTINUE-WATCHING (6 из 8 линз сошлись)
Сейчас: карточка `onEnter` → `playVideo` (~L550) → `Lampa.Player.play` сразу, **без detail-экрана, без timeline, без записи позиции** (grep timeline/history/progress = пусто). Это **главный недостающий TV-паттерн** — на пульте потерять место в 40-мин видео и доскрабливать D-pad'ом = худшая боль.

**Инфраструктура (фундамент, всё остальное наследует):**
1. **Watch History store** — клон `Fav` (timestamped records `{id,source,title,thumb,url,position,duration,ts}`) в `Lampa.Storage`. EFFORT: med. Хук: новый `Hist` объект рядом с `Fav` (~L240).
2. **Resume через timeline** — на player `timeupdate`/`destroy` писать позицию; передавать `timeline:{hash,time,duration}` в `Lampa.Player.play` (~L581) → нативный скраббер прыгает на место. Хук: `playVideo` опции + `Lampa.Listener.follow('player',…)` рядом с существующим `destroy`-хэндлером (~L1795).
3. **«Продолжить» рейл/плитка на главной** — записи истории с прогресс-баром → resume по OK. Хук: CherryMain (~L1230).
4. **Прогресс-бар на карточках грида** — если есть запись, тонкая полоса снизу + затемнение тумбы («видел / 60%»). Хук: cardRender badge-блок (~L1288).
5. **«Недавнее» + post-play next** — после плеера предлагать related/next (частично есть REQ-4).

→ Делать как отдельный **History-батч** (фундамент #1/#2 → потом #3/#4).

## 🔒 Родительский гейт (safety, не nicety) — accessibility
Для adult-плагина **нет защиты входа**. IDEA: PIN-гейт на вход в Cherry (клон sync-PIN-флоу), опционально blur тумб до подтверждения. EFFORT: med (~как sync-PIN). Топ-рекомендация линзы accessibility — единственный реальный дефект безопасности, а не комфорт.

## 🔎 Недавние запросы поиска (search)
Ввод с пульта мучителен. IDEA: перед клавиатурой показывать `Lampa.Select` с **недавними/подсказками** запросами (Storage). EFFORT: easy. Хук: search `onEnter` перед `Input.edit`.

## ⚙️ Консолидация настроек (settings)
Уже зарегистрирован Cherry-компонент в `SettingsApi` (~L1752), но почти пустой; ключ/PIN правятся «через Storage» (невозможно с пульта). IDEA: все настройки в нативный экран Lampa Settings — **proxy key, sync PIN, preview, + будущая панель вкл/выкл источников + safe-mode**. EFFORT: easy-med. Хук: `SettingsApi.addParam` (~L1746-1758).

## 🚀 Первый запуск (onboarding)
Новый юзер видит 27 безликих плиток-букв + тост с dev-инструкцией («измените cherry_proxy_key в Storage»). IDEA: само-удаляющаяся плитка-приветствие (`_kind:'welcome'`, gated `cherry_onboarded`) → краткий гайд (выбери источник → удержи OK для избранного → PIN для синка); + переписать/убрать dev-тост; + дефолт-фокус на источник, не на «Поиск». EFFORT: med. Хук: CherryMain results (~L1448), startPlugin (~L1736).

## 🎨 Микро-взаимодействия / полировка (microinteractions)
- **Анимация избранного** — `Fav.toggle` только Noty; добавить заливку сердца/scale-пульс на карточке. EFFORT: easy.
- **Скелетоны грида** вместо спиннера (>300ms). EFFORT: med.
- **Лого/иконка источника** в бейдже вместо текста (узнаваемость). EFFORT: med.
- **Empty-иллюстрации** вместо голого текста. EFFORT: easy.
- Консистентность иконок (emoji ⌕♥⟲ на плитках → вектор). EFFORT: easy.

## 🏠 Дизайн главной (home-design)
Плоская сетка букв vs **контент-рейлы**: «Продолжить» (из истории) → «Избранное» → пер-источник превью-ряды / трендинг. Богаче и сразу ценно. EFFORT: large (зависит от истории). Минимум — добавить рейл «Продолжить» первым.

## 🎬 Экран деталей (player-detail)
OK на карточке прыгает прямо в плеер — нет экрана с метаданными/related/resume. IDEA: лёгкий detail-экран (или хотя бы resume + post-play next). Частично закрывается History-батчем.
