# Cherry — UI/UX аудит вёрстки (2026-06-04)

Комплексный аудит после миграции на `Lampa.InteractionCategory`. Источники:
- Self-audit вёрстки Cherry (агент ui-designer по `plugin.js`)
- Сравнение с рабочими референсами `sisi_full.js` («Клубничка») и `adultjs.js` (AdultJS)
- Гайдлайны скилла `ui-ux-pro-max` (адаптированы под 10-foot TV / D-pad)

---

## Главная находка (root cause)

Миграция на `InteractionCategory` **осиротила весь кастомный слой вёрстки**:
- 6 шаблонов (`cherry_card`, `cherry_source_card`, `cherry_group_label`, `cherry_source_row`, + тела `cherry_main`/`cherry_grid`) — **не используются** (InteractionCategory строит свой DOM из стокового `.card`).
- ~300–390 строк CSS (`.cherry-card*`, `.cherry-grid*`, `.cherry-source-*`, `@keyframes cherry-spin`) — **мёртвый код**.
- Живут **только 2 правила**: `.cherry-cat .card__view` (16:9) и `.cherry-cat .card__img` (cover).

**Следствие:** весь задуманный фокус-глоу, бейдж длительности, обрезка заголовка, индикатор избранного, кастомный спиннер/empty — **на экране отсутствуют**. Юзер видит сток Lampa + наши 2 правила.

**Важно (валидация):** sisi и AdultJS используют **тот же подход** — стоковый `.card` + InteractionCategory. То есть наш переезд правильный. Более того, **наш 16:9 лучше** референсов: они льют горизонтальные превью в постер 2:3 (crop), а мы сделали честный 16:9.

### P0 — Тех.долг (по принципам владельца — обязательно)

| # | Что | Где | Эффект |
|---|---|---|---|

### P1 — Высокий эффект, дёшево (1–3 строки каждое)

| # | Что | Где | Из референса |

### P2 — Видимая полировка (нужно твоё решение по вкусу)

| # | Что | Где | Заметка |
|---|---|---|---|
| 2.1 | **Фокус карточки** — решить: оставить сток Lampa (как референсы) ИЛИ добавить брендовый розовый ring `.cherry-cat .card.focus .card__view{box-shadow:0 0 0 .18em #e75480...}` | новый scoped CSS | Референсы живут на дефолте. ## Рекомендуемый порядок внедрения

1. **P0** (удалить мёртвый код) — чистит почву, обязательно по принципам.
2. **P1** (ambient backdrop + dwell-превью) — максимум эффекта на строку.
3. **P2** (фокус-ring + заголовок + главная-пикер) — видимая полировка, после твоего решения по вкусу.
4. **P3** по запросу (фильтр в заголовке, error-state, атрибуция, global search).
5. **P4** — отдельное обсуждение.
