# Cherry — бесконечный скролл: аудит 24 каналов (2026-06-04)

Проверка пагинации во всех сценариях (категории, сортировки, поиск, all-sources) по каждому
каналу: 24 агента curl-проверяли page1/2/3, поведение в конце списка и корректность категорий.
Триггер: pornhub/amateur и xvideos/amateur не листались.

## Корневые причины (2 класса)
1. **`total_pages = page+1`** (было) → InteractionCategory грузил одну доп. страницу и **останавливался**.
   Эталон sisi отдаёт щедрый total (`||30`). → Фикс: `_derivePages` отдаёт `page+50` пока страница
   ≥ полупустой, кап на короткой/пустой. Перевыдаётся каждой страницей → бесконечно пока есть контент.
2. **Конец списка не пустеет** → щедрый total_pages = **бесконечные дубли**. Два подвида:
   - **CLAMP/WRAP**: сайт всегда отдаёт полную страницу (pornhub API), либо повторяет
     последнюю/первую (lenporno, porndig, tizam, jopaonline).
   - **page игнорируется**: каждая страница = page 1 (xnxx `/tags/`, xvideos `/best/`,
     non-category sort-фиды pornve/hellporno/hqporner/ebun).

## Универсальный фикс: dedup-guard в гриде
`CherryGrid` отслеживает виденные `id@source`; каждая новая страница фильтруется до НОВЫХ карточек;
если страница не дала **ни одной новой** → конец списка → стоп. Одним махом убивает бесконечные
дубли на ВСЕХ clamp/wrap/ignored-page каналах. Чистые каналы не затронуты.
+ **xnxx категории**: `/tags/` (игнорит page) → `/search/{slug}/{page}` (листается); xnxx-sort убран.

## Реалистичные тесты

### Юнит (vitest, `test/cherry-engine.test.mjs`, `cherry-ux-v2.test.mjs`)
- `_derivePages`: ≥полстраницы → `page+50`; <половины → `page` (кап); пусто → `page`.
- **dedup-guard**: смоделировать nextPageReuest, где page2 возвращает те же id, что page1 →

- per-channel browse URL: page2 строится корректно (категория+сорт+страница в нужной позиции),
  xnxx категория = `/search/{slug}/{page}` (не `/tags/`).

### Ручные (на устройстве, по каждому каналу)
Сценарий A — **категория**: открыть канал → выбрать категорию (напр. amateur) → листать вниз →
карточки догружаются БЕЗ повторов, и поток останавливается, когда контент закончился (нет вечных дублей).
Сценарий B — **сортировка**: выбрать сортировку → листать → порядок соответствует, догрузка идёт.
Сценарий C — **похожие названия** (all-sources): открыть → листать → подгружается со всех источников.
Сценарий D — **похожие** (related): один блок рекомендаций сайта (1 страница — норм).
Ключевая проверка: **нет бесконечных одинаковых карточек** (старый баг clamp/ignored-page) и
**нет преждевременной остановки** (старый баг page+1).
