# Cherry — глубокий UI/UX аудит (2026-06-06, 7 агентов + ui-ux-pro-max)

10-foot UI / D-pad. Привязано к реальному CSS/cardRender в `plugin.js`. Линии примерные.
Большинство правок — **easy CSS/мелкий JS с высоким impact** → отличный quick-win батч.

## 🔝 Сквозные находки (несколько линз сходятся)

### 1. ⏱ Превью без dwell-таймера — стартует мгновенно на фокусе (HIGH, easy)
`_startPreview` вызывается прямо в `onFocus` (~L1351). При D-pad-прокрутке ряда каждый промежуточный кадр запускает `video.load()+play()` → **jank, мерцание, расход трафика на TV**. *(Линзы: focus, motion, reference — единогласно «главный поведенческий разрыв vs sisi».)*
**Фикс:** dwell ~500-700ms: `_previewTimer = setTimeout(()=>_startPreview(...), 600)` в onFocus; `clearTimeout(_previewTimer)` в `_stopCurrentPreview`. Превью только на карточке, где остановился.

### 2. 🎯 Слабый фокус — `scale(1.04)` + только нативная рамка (HIGH, easy)
`.cherry-cat .card.focus .card__view{transform:scale(1.04);transition:.12s}` (~L1535). 4% зум незаметен на 3м; своего кольца нет → на тёмной теме фокус = тонкая линия.
**Фикс (на `.card__view`, чтобы не было двойной рамки):**
`transform:scale(1.07);box-shadow:0 0 0 .22em #e75480, 0 .6em 1.4em rgba(0,0,0,.6);border-radius:.4em;transition:transform .18s ease, box-shadow .18s ease;`

### 3. 🏷 Бейджи мелкие + 4 угла заняты (HIGH, easy)
`.cherry-src-badge .72em`, `.cherry-dur/.cherry-views .78em` (~L1549-1551) — ниже ~22px-порога читаемости на 1080p/3м. И **4 бейджа** (source TL, HD TR нативный, views BL, dur BR) перегружают + нативный HD-слот стилистически не совпадает.
**Фикс:** размеры → src `.85em`, dur/views `1em`, `font-weight:700`, `padding:.18em .55em`; **HD объединить в dur-пилюлю** (убрать `v.quality=v.hd`, ~L702, рендерить «HD · 12:34» в BR) → 3 угла; + **нижний градиент-scrim** под бейджами для контраста на светлых тумбах.

### 4. ✅ Меню без active-state (MED, easy)
`_openSort`/`_openCat` (Lampa.Select.show) не помечают текущий выбор; заголовок меню = имя источника, не активный фильтр.
**Фикс:** добавить `selected:` (индекс текущего sort/category) в Select.show; заголовок грида/меню = «{категория} · {сортировка}».

### 5. 🔁 Error/empty — тупик без Retry на пульте (MED, med)
`comp.empty(cherry_load_error)` (~L1150) — сообщение БЕЗ фокусируемого действия → с пульта только Back. all_sources total-failure тоже молчит.
**Фикс:** в error-ветке добавить фокусируемый «Повторить» → `comp.create()` (или «Открыть фильтры» → openActionsMenu). + крупнее текст empty/error: `.activity .empty__descr{font-size:1.5em;line-height:1.4;}`.

### 6. 🎨 Контраст плиток-букв дома (MED, trivial)
`_tileColor` (~L1382) даёт светлые hsl (жёлтый/зелёный) → белый текст плохо читается.
**Фикс:** `hsl(h,55%,38%)` (понизить lightness) — чинит все плитки разом.

### 7. 🎞 Motion-длительности (MED, easy)
`transition .12s` (120ms) ниже TV-окна 150-300ms → фокус «дёргается». Превью появляется поп-ом без fade.
**Фикс:** `.18s` на focus; fade-in для `.cherry-card__preview` (opacity .25s).
