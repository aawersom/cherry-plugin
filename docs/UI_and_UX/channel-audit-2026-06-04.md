## СИСТЕМНЫЕ баги (чинить один раз — помогает многим каналам)

### S1 — `total_pages` фальшивый/хардкод почти везде (HIGH, ~14 каналов)
Два режима поломки:
- **=1 / нет ключа** (pornhub, jopaonline-search, lenporno, perfektdamen, tizam, youjizz) → бесконечный скролл **не догружает** (UI думает «1 страница»).
- **хардкод 10 / синтетический `p+10`/`p+5`** (3movs, porndig, xozilla, 24rolika, xnxx, xvideos, pornone) → UI листает **за конец** → пустые/дубли.
**Фикс:** парсить реальное число страниц из разметки (последняя ссылка пагинации) в каждом `_pages`/`pagesRx`; для API — взять реальный ключ. Сделать общий помощник `_lastPage(html, rx)` и не возвращать константу.

### S2 — `views` почти везде `0` + нет HD/4K-бейджа (LOW, ~15 каналов)
`views: 0` захардкожен в большинстве парсеров; качество (HD/4K) сайты отдают (`hd-button`, `video-hd-mark`), но не парсится. Метаданные карточек бедные.
**Фикс:** распарсить views + HD-флаг где сайт даёт; показать (views — уже есть слот, HD — в `quality`).

### S3 — Сортировки «потеряны» (sorts:[]) или игнорятся (MEDIUM, ~8 каналов)
crocotube/pornone/eporner/ebun/3movs/porntrex имеют `sorts:[]`, хотя сайт поддерживает (часто **path-сорты** `/most-viewed/`, которые kvs-движок через `?sort_by=` выразить не может). Плюс ~19 адаптеров вообще игнорят 3-й параметр sort.
**Фикс:** для path-сорт сайтов — добавить ветку построения URL с сегментом; завести их `cfg.sorts`. (Затрагивает browse-логику — по твоему запрету только с явного «делай».)

### S4 — Просмотр по модели/актрисе — мёртвый код везде (P0-возможность)
`browseByModel` реализован у pornhub и xvideos и **работает**, но **недостижим**: ни один парсер не кладёт `model` на карточку и в `onMenu` нет пункта «Модель». Инфраструктура (`model_url`-роутинг) готова — не хватает ~15 строк проводки.
**Фикс:** распарсить `model` в карточку (pornhub `pornstars[]` уже в JSON; xvideos — из видео-страницы) + пункт меню «Модель» → push `model_url`.

### S5 — preview угадывается (MEDIUM, xvideos/xnxx)
`preview = thumb.replace(.../preview.mp4)` — выдуманный sibling, часто 404. Реальное превью: xnxx `data-pvv`, xvideos `setThumbUrl`/`data-videopreview`, pornhub `data-mediabook`.
**Фикс:** парсить реальный атрибут превью из разметки.

## КЛЮЧЕВЫЕ баги по каналам (перепроверить на устройстве)

1. **pornhub — категории (CRITICAL).** cfg = числовые id (`6:BBW, 31:Рыжие`), webmasters API требует **имена** (`category=BBW`, `category=Anal`). Числа → `{Category does not exist!}` → **пусто**. Это вероятно тот самый «BBW пусто», что ты видел. Фикс: заменить id на имена API (`_cats('Asian:Азиатки,BBW:BBW,Anal:Анал,MILF:MILF,Big Ass:Большая жопа,...')`, `Redhead`/`Red Head` уточнить). Сорт: `tr/mr` невалидны (молча → most-recent); валидные: `mostviewed/rating/mostrecent/longest`.
2. **lenporno — всегда 240p (HIGH).** Сайт отдаёт `file:"[240p] url,[480p] url,..."` с **пробелом** в строке; парсер берёт первое = 240p. Фикс: разобрать все метки качества, брать высшую.
3. **jopaonline / youjizz / tizam — поиск сломан (HIGH/MED).** jopaonline+youjizz: DLE/404-throw съедает тело ответа (нужен `_fetchAny`); tizam `?s=` 404. Фикс: status-tolerant fetch + верный search-роут.
4. **spankbang — стрим сломан (HIGH, известно).** 403 на Deno+SOCKS5, нужен Playwright/другой путь. Категории `/s/` = поиск.
5. **3movs / porndig / xozilla / 24rolika — листают за конец (HIGH/MED).** total_pages хардкод (см. S1).

## Сравнение с референсами (sisi / AdultJS) — функционально

**Чего НЕТ у нас, есть у них (приоритет):**
- **P0 Просмотр по модели** — у обоих есть; у нас готовый, но мёртвый код (S4).
- **P1 Related шире** — у нас только pornhub/xvideos (2/24); kvs-движок мог бы дать общий `getRelated` (re-parse видео-страницы) сразу 5+ каналам. AdultJS делает up-next прямо в плеере (`Lampa.Player.playlist`).
- **P2 История/продолжить просмотр/resume** — нет вообще; sisi имеет серверную историю; Lampa даёт нативные timeline-хуки. Можно локально по образцу `Fav`.
- **P2 Фильтр категория×сорт (2 уровня)** — sisi submenu; у нас сорт и категория независимы.
- **P3 ParentalControl-гейт** перед входом в источник — есть у обоих, у нас нет.
- **HD/4K + views на карточке** — see S2.

**Где мы ВПЕРЕДИ:**
- 24 клиентских адаптера без бэкенда (sisi 100% зависит от сервера).
- **Поиск по всем источникам сразу** (агрегация) — нет ни у sisi, ни у AdultJS.
- 3-уровневое проксирование с пер-хост маршрутизацией + рекурсивный HLS-прокси — надёжнее обоих.
- Локальные избранные офлайн; 16:9 карточки + превью на фокусе; русские лейблы категорий.
