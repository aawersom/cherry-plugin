# Feature Gaps — что есть у конкурентов, чего нет в Cherry

Дата: 2026-06-03  
Фокус: функциональность, UX, меню, навигация (не прокси, не карточки, не воспроизведение)

---

## Что есть только у Cherry (наши уникальные фичи)

| Фича | Детали |
|---|---|
| **Локальные избранные** | localStorage, без аккаунта, мгновенно, сердечко на карточке. AdultJS не имеет избранных вообще. |
| **Бейдж модели прямо на карточке** | Фокусируемый элемент на карточке. У конкурентов — только в контекстном меню. |
| **Related после закрытия плеера** | У AdultJS related — playlist внутри плеера. У нас — отдельный грид после закрытия. |
| **Уникальные источники** | 24rolika, Tizam, PerfektDamen, HellPorno, CrocoTube, Analdin, 3Movs, PornVe, FamilyPorn, Xozilla — нет ни в одном из конкурентов. |
| **Глобальный поиск по всем источникам** | AdultJS — только per-source. Sisi — в Lampa Search, но не в самом плагине. |
| **Трёхуровневый прокси** | CF Worker SOCKS5 + Deno + опциональный VPS. Технически сложнее конкурентов. |

## Критические пробелы (есть у всех конкурентов, нет у нас)

### UX-1: Навигация — последняя карточка → следующая страница
**Что есть у конкурентов:** когда пользователь на последней карточке нажимает вправо/вниз — Lampa `InteractionCategory` автоматически вызывает `nextPageReuest` и подгружает следующую страницу.  
**У нас:** при последней карточке фокус просто останавливается. Следующая страница загружается только при скролле до 300px от низа — но на TV пользователи не скроллят мышью, они жмут пульт.  
**Влияние:** высокое — пользователь видит только первую страницу и думает что видео закончились.  
**Решение:** добавить в контроллер `cherry_grid` обработку `right`/`down` на последнем элементе → вызывать `loadPage(currentPage + 1)`.

---

### UX-2: Вправо = открыть фильтр/сортировку
**Что есть:** AdultJS и Sisi — `onRight = filter.bind(comp)`. Нажатие вправо в видео-гриде открывает панель фильтра/сортировки.  
**У нас:** вправо = следующая карточка. Фильтр нет кнопки-триггера в гриде.  
**Влияние:** среднее — пользователь не знает о существовании сортировки.

---

### UX-3: Кнопка фильтра в шапке приложения
**Что есть:** AdultJS и Sisi инжектируют SVG-иконку фильтра в `.head` Lampa, которая появляется только когда активен их грид.  
**У нас:** нет кнопки фильтра нигде кроме filter bar внутри грида (скрытой для источников без сортировки).  
**Влияние:** среднее — фильтр не обнаруживается.

---

### UX-4: Сортировка и категории для большинства источников
**Что есть:** AdultJS — сортировка для 20+ источников, категории для 15+. Sisi/xsena — серверная сортировка для всех.  
**У нас:** только Pornhub (3 опции) и Xvideos (2 опции). 22 источника без сортировки вообще.  
**Влияние:** высокое — пользователь не может найти нужное.  
**Решение:** добавить `cfg.sorts` для SpankBang, EPorner, HellPorno, Xozilla, Analdin, и др.

---

### UX-5: Настройки в Lampa Settings (не скрытые)
**Что есть:** AdultJS и Sisi регистрируют свой раздел в Lampa Settings через `SettingsApi.addParam`. Toggle предпросмотра виден в настройках приложения.  
**У нас:** предпросмотр скрыт за long-press на заголовке "Cherry" — не обнаруживается.  
**Влияние:** среднее — пользователь не знает что превью можно включить/выключить.  
**Решение:** `Lampa.SettingsApi.addParam` для Cherry.

## Значимые пробелы (есть у части конкурентов)

### UX-6: Per-source поиск из грида
**Что есть:** AdultJS и Sisi — кнопка "Найти" в панели фильтра источника.  
**У нас:** поиск только глобальный из главного экрана, нельзя поискать внутри конкретного источника.

---

### UX-7: Related видео через контекстное меню
**Что есть:** AdultJS и Sisi — "Похожие" в long-press меню на любой карточке (если источник поддерживает).  
**У нас:** related загружается только в фоне при воспроизведении PornHub/Xvideos и показывается после закрытия плеера. Нет возможности открыть похожие без воспроизведения.

---

### UX-8: Related как playlist внутри плеера
**Что есть:** AdultJS — `Lampa.Player.playlist(recomends)` — related видео видны как иконки прямо в плеере.  
**У нас:** related показываются как отдельный грид после закрытия плеера.

---

### UX-9: Задержка 1500мс перед стартом превью
**Что есть:** AdultJS и Sisi — 1500мс setTimeout перед запуском превью при фокусе. Предотвращает мерцание при быстром перемещении.  
**У нас:** превью запускается сразу при `hover:focus` без задержки.

---

### UX-10: Иерархические меню фильтра (2 уровня)
**Что есть:** Sisi — `submenu[]` в меню. Первый клик открывает субменю (например: Категория → [Список категорий]).  
**У нас:** один уровень `Lampa.Select` для sort и category отдельно.

---

### UX-11: Category × Sort matrix
**Что есть:** AdultJS (catsort) — выбранная категория сохраняется при смене сортировки и наоборот. URL строится из обоих параметров.  
**У нас:** sort и category независимы, нет комбинирования.

---

### UX-12: Подсказка как добавить в избранное
**Что есть:** Sisi — при открытии пустого списка закладок: *"Удерживайте ОК на видео для добавления в закладки."* (10 секунд).  
**У нас:** пустой экран избранного показывает только ☹ + "Нет результатов". Нет подсказки.

## Что есть только у xsena (серверная архитектура, не применимо напрямую)

Эти фичи требуют серверной части и не могут быть реализованы в чисто клиентском плагине без бэкенда:
- Серверные закладки (мультидевайс синк)
- Серверная история
- VIP-контент и тиры доступа
- Настройки источника per-provider (mirror/CORS/VPN)
- Гео-фильтрация
- Веб-каталог
- Android APK
- RCH WebSocket relay (это Sisi, но тоже требует сервер)
