# Cherry — дорожная карта улучшений (2026-06-06)

Приоритеты: P0 (срочно/риск) → P1 (высокая ценность, дёшево) → P2 (средне) → P3 (крупно/опц.).

## 🔴 P0 — Безопасность (срочно)
1. **Утечка прокси-кредов.** `workers/cherry-proxy/src/index.js:18-23` — живые SOCKS5/резидентные креды (`45.91.209.155`, user `hgTr0m`, pass `6H3nY1`) захардкожены, **оба репо ПУБЛИЧНЫЕ**, и креды уже в git-истории (1 коммит). → **(a)** РОТИРОВАТЬ у провайдера прокси (история = креды сожжены, переписью не вернуть приватность гарантированно); **(b)** перенести `PROXIES` в CF Secret (`env.PROXIES_JSON`), убрать из кода; **(c)** аналогично проверить, что `PROXY_KEY`/`SYNC_SECRET` только в секретах. *(Владелец ранее считал git приватным — это не так.)*
2. **SSRF-релей.** `/proxy?url=` — открытый релей: любой может гонять трафик через воркер на произвольные URL. Добавить allowlist хостов (только наши 24 домена + их CDN) + лимит размера ответа.
3. **PIN синка слаб.** 4-значный PIN (`plugin.js:462,1478`, `index.js:349`) → перебор. Поднять минимум до 6-8 цифр; добавить cap размера тела `/favs` + `Cache-Control: no-store` на ответы `/favs`.

## 🟠 P1 — Дёшево и ценно (quick wins)
4. **Тестировать РЕАЛЬНЫЕ парсеры (убить дрейф L37).** Сейчас тесты копируют парсеры инлайн → код может быть сломан при зелёных тестах. Добавить в конец `plugin.js` guarded `if(typeof module!=='undefined') module.exports={...}` (браузер `module` не видит) → тесты импортируют настоящие функции. Воркер уже так делает (`index.js:478`). EFFORT: med, убирает целый класс багов.
5. **CI на тесты + channel-health.** Суита ~648 тестов идёт ~0.4с — завести GitHub Action; + scheduled прогон `channel-health.mjs` с алертом (ловит редизайны сайтов как spankbang АВТОМАТически). EFFORT: easy, наибольший ROI по надёжности.
6. **Детектор редизайна в адаптерах.** В каждом adapter-catch логировать `[Cherry] <id> fetch/parse failed` и «fetched N bytes, parsed 0 cards» — мгновенный сигнал поломки без падения. EFFORT: easy.
7. **`secToTime` баг часов.** `plugin.js:513-518` 90-мин видео рендерит «90:00» вместо «1:30:00». Добавить перенос часов. EFFORT: trivial. (UX+data обе линзы.)
8. **Fast-fail сломанных стримов.** spankbang/hqporner стрим висит у юзера. Guard known-broken-host в `playVideo` → сразу сообщение, не вечный плеер. EFFORT: easy.
9. **Превью dwell-таймер.** Запускать hover-preview только после паузы фокуса (анти-jank + экономия трафика на TV). EFFORT: easy.
10. **Worker-кэш листингов** (`index.js`): Cache API/KV на GET-листинги → пагинация и back-навигация = кэш-хиты. EFFORT: easy-med, заметно на TV.
11. **`worker-utils.test.js` чинится** (импорт `cloudflare:sockets`) → вернёт 22 security-теста; обновить `docs/TESTING.md` (там «~463», реально 648). EFFORT: easy.
12. **Удалить мёртвый код:** `_huyambaCards` (помечен DISABLED, `plugin.js:4980`), dead `proxyM3u8`/`blobUrls`, устаревшие line-комментарии в тестах. EFFORT: easy.

## 🟢 P3 — Фичи (крупное, по ценности)
18. **Панель источников** (xsena-style, #1 по value/effort): вкл/выкл каждого канала (Storage-фильтр над SOURCES), фильтр категорий/LGBT, **живой статус источника** (маркеры из `channel-health` уже есть). Чистый UI, без риска парсеров.
19. **Родительский гейт** (~30 мин, клон PIN-флоу синка) — уместно для adult-плагина.
20. **История просмотров + resume** (Lampa поддерживает timeline) — заметная UX-фича.
21. **Регистрация в системный поиск Lampa** (глобальный поиск из главного меню).
22. **Серверный парсинг** (как xsena premium): воркер парсит → отдаёт JSON/build() → снимает нагрузку/блокировки с устройства, открывает путь к мультиплатформе. Крупно.

## ✅ Верификация находок по коду (2026-06-06, адверсариально)
Каждый P0/P1-claim перепроверен прямо в коде:
- **P0.1 утечка прокси-кредов — ПОДТВЕРЖДЕНО** (`index.js:18-23`, оба репо PUBLIC, в git-истории). Реально, срочно.
- **P0.2 SSRF — УТОЧНЕНО (понижено с «SSRF»):** приватные хосты УЖЕ блокируются (`isPrivateHostname`, `index.js:402`) — классического SSRF НЕТ. Реальная проблема: `/proxy` пускает ЛЮБОЙ публичный URL, а гейт — только `PROXY_KEY`, который…
- **🆕 НОВОЕ: `PROXY_KEY` = `'1206'`** — это клиентский дефолт И он буквально написан в lang-строке (`plugin.js:1599` «ключ прокси — 1206»). Значит гейт `/proxy` и `/favs` бессмысленный → воркер = открытый прокси на любой публичный URL, жгущий ПЛАТНЫЙ резидентный пул. **Единственная реальная защита — allowlist хостов** (наши 24 домена + их CDN), т.к. клиентский ключ обязан быть публичным. Сила ключа роли не играет.
- **P0.3 PIN 4 цифры — ПОДТВЕРЖДЕНО** (`plugin.js:438/462/1478`, `index.js:349`), но смягчено rate-limit ~60/мин + HMAC-бакетом. Поднять до 6-8 — гигиена, не критично.
- **🆕 ХОРОШО (подтверждено отсутствие утечки):** `SYNC_SECRET` и PIN/email владельца в коммитнутом коде ОТСУТСТВУЮТ (только SOCKS5-креды). `eval`/`Function`/`document.write` в плагине НЕТ.
- **❌ XSS — НЕ ПОДТВЕРЖДЕНО (ложная находка агента, убрано):** cardRender вставляет в DOM только НАШИ данные (`os.name`, `secToTime`=число, `vstr`=число, `_initial`=буква) — распарсенные заголовки сайтов через innerHTML НЕ идут. XSS-вектора нет.
- **P1.7 secToTime — ПОДТВЕРЖДЕНО** (`plugin.js` `secToTime`, нет часов).
- **P1.12 мёртвый код — ПОДТВЕРЖДЕНО** (`_huyambaCards` тело на L5007 при DISABLED-адаптере; VePorn удалён).
- **P2.16 always-on логи синка — ПОДТВЕРЖДЕНО** (`plugin.js:470,474`).

**Итог правок:** P0.2 переформулирован (allowlist, а не «SSRF»); XSS снят; добавлено новое про `PROXY_KEY='1206'`; подтверждено отсутствие прочих утечек секретов.
