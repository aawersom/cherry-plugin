## Что такое xsena.red
Сервис-агрегатор adult-контента для ТВ/плееров. Стек: **Blazor Server (.NET)** поверх
SignalR-вебсокета (UI рендерится на сервере, поэтому через curl не интроспектируется — нужен
браузер с логином). Подключает контент к: **Lampa, MSX, ForkPlayer, Android apk, Media Station X**.
Сам контент не хранит — отображает со сторонних сайтов. Монетизация: премиум + оплата.

Разделы: Главная · Устройства · Настройки · Премиум · Мои счета · Справка · Телеграм.

## «Мониторинг» = Настройки → таблица источников
Ядро того, что владелец назвал «мониторингом». По каждому источнику строка с колонками:

| Колонка | Значения | Смысл |
|---|---|---|
| **Источник** | PornHub, Xvideos, Xhamster, Ebalovo, HQporner, Spankbang, Eporner, … | список каналов |
| **Состояние** | Включён / Выключен | пользователь сам вкл/выкл каждый источник |
| **Парсер** | Устройство / **Сервер** (премиум) | где парсить: на устройстве или на сервере xsena |
| **Видеопоток** | Прямой / **VPN** (премиум) | как отдавать стрим: напрямую или через VPN |

Дополнительно (из changelog и настроек):
- кастомные **зеркало / cors / vpn** на каждый источник;
- **отключение LGBT-контента**;
- свой **CorsProxy** — обход ограничений устройств (MSX) и провайдера (РКН);
- премиум: серверный парсинг, VPN-стрим, конвертация avif/webp→jpg;
- привязка **устройств** по идентификатору (напр. «Sony / snkxlrgy»);
- альтернативные адреса плагина, поддержка ForkPlayer, xsena.apk.

Журнал изменений показывает, что они **активно чинят источники** («Исправлен Xhamster, Cam4»,
«Добавлено 12 новых источников», «Обновлён CorsProxy») — т.е. ведут поддержку каталога.

## Рекомендация (что реально стоит делать)
**MVP «панель источников» внутри плагина (Lampa-нативно):**
1. Вкл/выкл каждого из 24 каналов (скрыть ненужные/временно нерабочие — напр. spankbang).
2. Опционально: свой прокси/зеркало на канал (override глобального).
3. Фильтр категорий (LGBT и т.п.).
4. Опц.: живой статус источника (на базе channel-health/E2E).

Серверный парсинг, VPN-стрим, мультиплатформа — большие отдельные проекты (и у xsena это
премиум-монетизация). CorsProxy для обхода РКН у нас уже есть.
